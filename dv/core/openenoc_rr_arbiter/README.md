# openENOC Round-Robin Arbiter Test Suite

## Running Tests

From this directory, run `./run_tests.sh pytest` for the parameter sweep,
`./run_tests.sh waves` for a default four-port FST waveform, or
`./run_tests.sh clean` to remove simulation artifacts.
