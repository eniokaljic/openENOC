# openENOC Endpoint Direct AXI Stream Test Suite

## Running Tests

From this directory, run `./run_tests.sh pytest` for the tests,
`./run_tests.sh waves` for an FST waveform, or `./run_tests.sh clean`
to remove simulation artifacts.
